# מעגל החלטה

מעלים שאלה, שומעים את כולם, מחליטים יחד.

כלי קהילתי לקבלת החלטות: פותחים שאלה מרכזית, כל משתתף מוסיף דעה (בעד / נגד / מתלבט) או שאלה, מנקדים דעות של אחרים, ובסוף מסכמים את ההחלטה ונועלים את הדיון.

**האתר החי:** https://claude.ai/artifact/GPt1xhEtxMP18JsRs7dSzM

## מה יש בדף

- רשימת שאלות פתוחות ושאלות שהוחלטו
- דופק הקהילה – העמדה האחרונה של כל משתתף
- ענן הדעות – גודל לפי סך הניקוד
- ניקוד 1–5 לכל דעה, תגובות ותשובות
- אפשרות לפרסם בעילום שם
- סטטיסטיקות כניסה והשתתפות

## הערה טכנית

`index.html` הוא קובץ יחיד (HTML, CSS ו-JavaScript). שמירת הנתונים וזיהוי המשתמשים נשענים על סביבת הארטיפקטים של Claude (`window.claude`), ולכן מחוץ ל-Claude הדף נטען אבל לא מציג ולא שומר דיונים.
